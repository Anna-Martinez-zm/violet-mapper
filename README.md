# Violet Mapper

![License](https://img.shields.io/github/license/Anna-Martinez-zm/violet-mapper) ![Python](https://img.shields.io/badge/python-3.10-blue) ![CI](https://github.com/Anna-Martinez-zm/violet-mapper/actions/workflows/map.yml/badge.svg)

JSON Schema to Python dataclass mapper. Generates type-safe dataclass code from JSON Schema definitions.

## Installation

```bash
pip install violet-mapper
```

## Usage

```bash
violet --help
```
